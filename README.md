Lyric Cove 🎵

Lyric Cove is a simple Content Management System (CMS) for creating and managing song tracks and lyrics.

The system allows users to register and log in, then manage tracks through the dashboard. It also provides REST API endpoints for creating, retrieving, updating, and deleting tracks.

FEATURES:

User Registration
User Login
Dashboard
Create/Add Track
View Tracks
Update Track
Delete Track
REST API for Track Management
API Testing using Postman

Technologies Used:

PHP
MySQL
HTML
CSS
JavaScript
REST API
Postman
